# Description de la Solution — SAFINUM 2026

**Problème** : Les services financiers numériques camerounais sont quasi-exclusivement rédigés en français ou en anglais, privant des millions de citoyens d'un accès bancaire autonome et sécurisé dans leurs langues nationales. Modifier le code source des banques est interdit, et toute erreur altérant un montant ou un bénéficiaire constitue un risque financier critique.

**Solution** : SAFINUM Accessibility est une couche d'accessibilité non-intrusive déployée via une extension Manifest V3 avec widget Shadow DOM, sans modification du site cible (https://safinum.cm/hackathon-test). Elle garantit l'intégrité absolue des montants, frais et bénéficiaires par masquage déterministe par jetons (`protect.py`). La méthode repose sur un triptyque transparent : brouillon IA + recoupement lexical (projet Mélac) + garde-fou d'intégrité avec affichage bilingue parallèle pour les données sensibles. À ce stade, 0/84 chaînes sont validées par un locuteur natif (statut `machine_suggested` affiché en permanence) ; la validation native certifiée est programmée avant la finale (26-28 novembre) via `catalogue/fiche_validation.csv`. Un catalogue embarqué assure une démonstration 100 % hors ligne sans collecte de données personnelles.
